## 数据类型

### 整型
| 长度           | 有符号 | 无符号 |
| ---           | ---   | ---   |
| 8-bit         | i8    | u8    |
| 16-bit        | i16   | u16   |
| 32-bit        | i32   | u32   |
| 64-bit        | i64   | u64   |
| 128-bit       | i128  | u128  |
| arch(32/64)   | int   | uint  |

### 浮点类型
浮点类型有两个: `f32` 是单精度浮点数，`f64` 是双精度浮点数, 默认类型是 `f64`, 都是有符号的。

### 布尔型
布尔类型有两个可能的值：`true` 和 `false`, 使用 `bool` 表示

### 字符类型
字符类型用单引号声明 `char` 字面量

### 字符串
字符串使用双引号声明字符串字面量

### 复合类型
元组（tuple）和数组（array）
